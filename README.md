# Yadukrishnan's blog

Source of [yadavan88.github.io](https://yadavan88.github.io), built with [Astro](https://astro.build) and the [AstroPaper](https://github.com/satnaing/astro-paper) theme (MIT).

## Development

```
pnpm install
pnpm dev      # local preview
pnpm build    # production build into dist/
```

Posts live in `src/content/posts/` and are deployed to GitHub Pages on every push to `master`.
